⚡ Sincronización Automática Cloud (Balneario 24/7)

Para que tu MikroTik físico en el balneario inyecte las fichas vendidas por WhatsApp en tiempo real (incluso detrás de la ONT sin IP pública fija), pega este comando en la New Terminal de Winbox:

/system script add name="sync-cloud-vouchers" policy=ftp,reboot,read,write,policy,test,password,sniff,sensitive,romon source=":do {\r\n :local cpu [/system resource get cpu-load];\r\n :local up [/system resource get uptime];\r\n :local ver [/system resource get version];\r\n :local mem [/system resource get free-memory];\r\n /tool fetch url=\"https://royota-bot.onrender.com/api/mikrotik/sync/vouchers.rsc?token=RoyotaCloud_SyncToken_2026_SecureKey&cpu=\$cpu&uptime=\$up&version=\$ver&mem=\$mem\" dst-path=\"sync.rsc\" check-certificate=no;\r\n :delay 1s;\r\n :if ([/file find name=\"sync.rsc\"] != \"\") do={\r\n /import file-name=\"sync.rsc\";\r\n /file remove \"sync.rsc\";\r\n };\r\n} on-error={}" /system scheduler add interval=40s name="cloud-sync-scheduler" on-event="sync-cloud-vouchers" start-time=startup

✅ Este script consulta la nube cada 40 segundos mediante token criptográfico, reporta telemetría real e inyecta al instante cualquier ficha comprada por clientes.

💡 ¿Cómo interactúa el cliente?

1. Consulta de Planes:
Cualquier saludo o palabra como "hola", "planes", "precios", "comprar" activará la respuesta automática con los planes vigentes del sistema y los datos de pago.

2. Envío de Comprobante:
El cliente transfiere a tu Daviplata o Llave Bre-B (3174251419) y envía la foto de la transferencia al chat.

3. Verificación con IA & Anti-Fraude:
Gemini Flash lee el monto, verifica que el destino sea tu número y confirma que el número de aprobación no se haya utilizado antes.

4. Entrega Instantánea:
El bot reserva o genera la ficha del plan pagado y le responde con su código y las instrucciones de conexión al Wi-Fi.
